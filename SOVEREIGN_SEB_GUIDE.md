### 1. Download & Install (Version 3.x Recommended)
* Windows 10/11: [Safe Exam Browser 3.7.0 for Windows](https://safeexambrowser.org/download_en.html) download godhaa.
* Kompiitaroota mana barumsaa hunda irratti Install godhaa.

* **General Tab:** 
  - Start URL: `https://ais-pre-zyaq3mnjmkd55f6qamhtvh-107893339879.europe-west2.run.app`

### 3. Identity Protocol (Login Credentials)
* Barattoonni akka armaan gadiitti seenu:
  - **Username:** Maqaa barataa (First Name)
  - **Password:** NID (National Identity Number)
* Hub: Email hundi bifa `[NID]@students.iftu.edu.et` jedhuun system keessatti cufamee jira.

### 4. Lockdown Protocol (Exam Engine)
* Admin Dashboard (IFTU) irratti 'Exam Architect' keessaa qorumsa filadhaa.
* 'Safe Exam Browser Required' kan jedhu 'ON' godhaa.
* 'Registry Open' kan jedhu 'ON' godhanii barattoonni akka enroll godhatan godhaa.

### 5. Deployment (Raawwii)
* Failii `.seb` qophaa'e Flash Drive'n kompiitara barattootaa hunda irratti fabaa.
* Barattoonni linkii desktop irratti uumame kanaan qofa qorumsa fudhatu.

**HUB:** Barataan SEB malee browser biraan (Chrome/Edge) banyee qofaan banuu yaalu "CRITICAL SECURITY: SEB REQUIRED" ergaa jedhuun dhowwama.
